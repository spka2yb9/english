# English Path Reach B2

日本語母語話者が CEFR B2 へ段階的に進むための、ログイン不要の英語学習アプリです。
発音・文法・語彙を、短い教材、想起練習、即時フィードバック、間隔を空けた復習、英文音声で学べます。

## 収録内容

- 文法: 5段階、33ユニット、117セクション、672問。全問に解説と正解英文音声。セクションごとに完了ボタン。
  全117セクションにタイムライン・対比・構造図のいずれかを1つ以上置き、文法の仕組みを図で確認できます。
  各セクションに例文10文と、その10文から作る並べ替え10問(計1,170問)。
  B2は到達判定に足る演習量を確保するため1セクション10問(B2計340問)
- 語彙: **8,000見出し語**(B2到達の目安は6,500〜7,500語)。日常の具体名詞から抽象語・句動詞・慣用表現まで。単語音声、例文音声、
  文脈付き和訳、全語に語源・コアイメージ中心の解説文(「覚えるヒント」は常時展開)と
  コロケーション。高頻度句動詞145件と定型表現31件を独立項目として収録
- 発音: 39のIPA項目、13の最小対、schwa・強勢・弱形・連結・語末子音などの実践トピック。
  全記号×10語=400語の発音記号穴埋め演習(単語音声つき、誤答は似た音の記号、1回10問をランダム出題)
- ダウンロード: 文法のレッスン／ユニット／全体を Markdown または日本語PDFで保存
- 音声練習: 音読・シャドーイングとディクテーション。既存の5,922文から実行時に出題するため、問題データを持たない
- 多読: A2・B1・B2 各36本の計108本。段落ごとの音声・和訳・語注と、内容理解設問540問(すべて自作)。
  レベルごとに折りたためる一覧と、本文ごとの読了ボタン
- 進捗: 文法完了、語彙の正誤履歴、語彙の日別ログ(最大120日。英単語ページで定着量・推移・練習量をグラフ表示)、
  音声練習と多読の履歴を `localStorage` に保存。
  任意で private Gist へ同期し、端末間で引き継ぎ可能

データを消してもアプリが初期状態へ戻るだけで、バックエンドは必要ありません。

複数の端末で進捗を引き継ぎたい場合のみ、ホーム画面から GitHub の `gist` スコープのトークンを登録すると、
進捗を自分の private Gist に自動保存します(サーバ不要・月額0円)。保存内容はブラウザに持つのと同じ JSON だけです。
手順は [docs/sync.md](docs/sync.md) を参照してください。

## 開発

```bash
npm install
npm run dev
```

品質チェック:

```bash
npm test
npm run validate:content
npm run lint
npm run build
```

教材を追加・変更したら、サマリー(件数・can-doカバレッジ)を再生成します。
ズレは `validate:content` が検出します:

```bash
npm run summary
```

生成したコンテンツを取り込む前の機械検査:

```bash
npm run validate:batch -- candidates.json
```

構造・誤答注記の有無・レベル逸脱(未習語率と平均文長)・近似重複・音声適合を検査します。
解答の妥当性だけは機械検査では判定できないため、取り込み前に別モデルで独立に解かせて正解の一致を確認してください。

## デプロイ

`main` に push すると GitHub Actions が GitHub Pages へ公開します。初回設定と注意点は
[docs/deploy.md](docs/deploy.md) を参照してください。

## 主な構成

```text
src/
  components/          再利用UI、音声ボタン、教材ブロック、クイズ、図解
  content/             UIから独立した文法・語彙・発音データと型
  pages/               ダッシュボード、発音、文法、語彙
  services/            TTS、進捗、SRS、演習生成、入力採点、Markdown/PDF生成
docs/
  grammar-curriculum.md
  learning-design.md
  vocabulary-methodology.md
```

文法は同じ `GrammarLesson` データから React UI、Markdown、PDFを生成します。語彙セッションは純粋関数の
状態機械で、最初の10語のうち「わからない」と答えた語だけを、0語になるまで再出題します。

## 音声について

共有 `SpeechService` の背後でブラウザの Web Speech API を使います。既定は `en-US`、速度は通常 `1.0` と
学習用の低速 `0.5` です。音量はAPIの上限に固定し、冒頭が欠けにくいよう教材本文と同じ発話の先頭に短い
開始キューを入れています。新しい音声を再生すると前の音声を停止します。TTS非対応環境でも、英文と教材はすべて文字で
利用できます。実際の声質はOSとブラウザにインストールされた音声に依存します。
