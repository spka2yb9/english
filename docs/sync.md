# 端末間同期(private Gist)の手順

PCとスマホなど複数の端末で学習進捗を共有するための設定です。
保存先は自分の GitHub の **private Gist** なので、サーバもDBも要らず月額0円で運用できます。

対象は1人1アカウント。共有アカウントや複数人での利用は想定していません。

## 保存されるもの

`english-progress.json` という1ファイルに、ブラウザが持っているのと同じ内容が入ります。

- 文法の完了セクション
- 語彙の正誤履歴と再学習フラグ
- 音声練習・文法クイズのSRS履歴
- 多読の読了記録
- 語彙の日別ログ(その日の練習語数と定着語数、最大120日)

教材そのものはアプリに内蔵されているので同期対象外です。

## 1. トークンを作る

ホーム画面の「端末間の同期」にある **トークンを作る** を押すと、スコープが選択済みの
GitHub のトークン作成ページが開きます。

1. **Note**: `English A2-B2`(自動で入る)
2. **Expiration**: 期限切れのたびに貼り直す手間を避けたいなら `No expiration`。
   期限を付ける場合は、切れた日に同期が止まる(学習データは各端末に残ります)
3. **Select scopes**: `gist` だけにチェックが入っていることを確認する。**他のスコープは付けない**
4. **Generate token** を押し、表示された `ghp_...` をコピーする(この画面を閉じると二度と表示されません)

> fine-grained token を使う場合は、Account permissions の **Gists: Read and write** だけを許可してください。

## 2. 1台目でサインインする

1. アプリのホーム画面を開く
2. 「端末間の同期」にトークンを貼る
3. **同期を有効にする** を押す

保存先の Gist が無ければ自動で作られます(private)。以降、この端末の進捗は自動保存されます。

## 3. 2台目以降でサインインする

同じ手順で、同じ GitHub アカウントのトークンを貼るだけです。
既存の保存先 Gist を自動で探して見つけるので、Gist の ID をコピーする必要はありません。

> **注意**: サインインすると、その端末のローカル進捗は Gist 側の内容で上書きされます。
> 2台目にだけ残っている進捗がある場合は、先に2台目でサインインして押し上げてから
> 1台目でサインインしてください。

端末ごとに別のトークンを作っても構いません(同じアカウントなら同じ Gist に届きます)。
スマホは入力が面倒なので、パスワードマネージャ経由で貼るか、端末ごとに発行するのが楽です。

## 動作

| タイミング | 動き |
| --- | --- |
| アプリ起動時 | Gist から取り込む。Gist 側が新しいときだけローカルを置き換える |
| 進捗を保存したとき | 3秒まとめてから Gist に書き込む |
| タブを離れる・閉じるとき | 未送信分をその場で書き込む |
| 通信に失敗したとき | 学習はそのまま続けられる。次の保存時に再試行する |

起動時の取り込みに成功するまで書き込みは行いません。オフラインで開いた古い端末が、
別端末の新しい進捗を消さないためです。

手動で今すぐ送りたいときは、ホームの **今すぐ同期** を押します。

## 確認する

<https://gist.github.com/> を開くと `english-progress.json` という Secret gist があります。
中身を見れば、いつ(`savedAt`)何が保存されているか確認できます。

## やめる・作り直す

| やりたいこと | 手順 |
| --- | --- |
| この端末だけ同期を止める | ホームの **サインアウト**。学習データは端末にも Gist にも残る |
| すべての端末で止める | GitHub の Settings → Developer settings → Personal access tokens からトークンを削除 |
| 保存データを消す | gist.github.com で該当 Gist を削除。次のサインインで新しい Gist が作られる |

## 制限

- **最後に保存した端末の内容が勝ちます**。2台で同時に学習すると、片方の進捗が消えます。
  端末を切り替えるときは、前の端末のタブを閉じてから次を開いてください
- トークンはブラウザの localStorage に平文で保存されます。共用PCでは使わないでください
- 保存先 Gist は、アカウントの直近100件の Gist から探します。それ以上ある場合は見つかりません
- 進捗が1MBを超えると Gist API の応答が切り詰められ、同期が止まります(学習データは各端末に残ります)

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 「トークンが無効です」 | コピーミス、期限切れ、削除済み。新しいトークンを作り直す |
| 「GitHubに接続できません (403)」「保存先の作成に失敗しました (403)」 | スコープに `gist` が無い。スコープを付け直したトークンを作る |
| 「進捗の取得に失敗しました (404)」 | 保存先 Gist が削除された。サインアウトして、もう一度サインインする |
| 端末間で内容が食い違う | 片方が古い状態で上書きした可能性。正しい方の端末で **今すぐ同期** を押し、もう片方を再読み込みする |
| 同期しているのに反映されない | 取り込みは起動時のみ。もう片方の端末はページを再読み込みする |
