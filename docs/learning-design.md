# 学習設計仕様(Learning Design)

このアプリケーションの教育的な設計方針を定義する。実装はこの仕様に従う。

## 対象学習者

- 日本語母語話者
- 現在のレベル: CEFR A2 前後(中学英語は一通り学習済み、抜けあり)
- 目標: CEFR B2
- 読解は比較的できるが、リスニング・音声認識が弱い傾向
- 専門的な言語学用語よりも実用的な理解を求めている

したがって: 解説は日本語、例文・語彙・演習は英語。すべての学習用英文は音声再生可能にする。

## Reach B2 戦略

1. **文法**: A2復習 → A2+ → B1 → B1+ → B2 の5段階、約110セクション。前提関係を明示し、
   大きなトピック(現在完了・関係詞・条件文など)は3〜15分で完結する小セクションに分割する。
2. **語彙**: A2〜B2水準の4,500見出し語を、想起練習(retrieval practice)ベースの
   5語セッション + 間隔反復で定着させる。
3. **発音**: 網羅的な音声学ではなく、日本人学習者が優先すべき音(R/L、TH、V/B、語末子音、
   schwa、強勢、弱形、連結)にフォーカスしたコンパクトなリファレンス。
4. **音声**: 「読めるが聞き取れない」学習者を作らないため、学習対象の英文は原則すべて
   その場で再生できる(en-US、通常速度 + スロー速度)。

## 学習科学の原則 → 実装マッピング

| 原則 | 実装 |
|------|------|
| 想起練習(Retrieval practice) | 語彙: 意味を見る前に「わかる/わからない」を自己判定。文法: 解説の後に必ずクイズ |
| テスト効果(Testing effect) | 全文法セクションに多肢選択クイズ。読むだけで終わるレッスンは作らない。B2は1セクション10問 |
| 即時フィードバック | 回答直後に正誤・正解・正解の理由・各誤答が誤りである理由を表示 |
| 間隔反復(Spacing) | 語ごとに次回出題日を持つ。連続正解で間隔を倍にし、間違えると次のセッションへ最優先で戻す。音声練習の文は実施回数だけを記録し、少ない文から順に1周ずつ回す(間隔反復には乗せない。「音声練習の出題」参照)。文法問題の正誤はレッスン内で記録し、進捗として持ち越す |
| インターリービング | 対比レッスン(過去形 vs 現在完了、will vs be going to 等)とクイズ内の類似構造混在 |
| チャンキング | 1セクション3〜15分。大トピックは複数セクションに分割 |
| 二重符号化(Dual coding) | タイムライン図・構造図・対比表を文法解説に併用 |
| 精緻化(Elaborative encoding) | 語彙に語形成・コロケーション・関連語・記憶フックを付与 |
| ワーク例(Worked examples) | 解説 → 例文(訳・ハイライト付き) → 対比 → クイズの順で段階的に足場を外す |
| 段階的難易度 | CEFRレベル順のカリキュラム、前提レッスンの明示。語彙の出題もレベルの低い語を優先 |
| 文脈学習 | 語彙は必ず自然な例文 + 和訳とセットで提示 |
| 反復露出 | わからない語が0になるまでセッション内で再出題(仕様上の必須動作) |
| 望ましい困難(Desirable difficulty) | 意味を隠した状態での自己判定、表面的な手がかりで解けないクイズ設計 |
| マルチモーダル | 英文テキスト + 同一英文の音声再生(通常/スロー) |

音声は「科学的に魔法の効果がある」ものとしては扱わない。テキスト・例文・想起・解説を
補完する1チャンネルとして位置づける。

## レッスン構造(文法)

各セクションは一貫して以下の構造を持つ:

1. **目標** — このセクションでできるようになること(日本語1〜2文)
2. **コアコンセプト** — 用語を避けた直感的な説明
3. **文型の視点** — そのセクションの文法を5文型(SV・SVC・SVO・SVOO・SVOC)で見たときの1〜2文
4. **構造図** — 英文を S / V / O / C / M に分けた分解図(構造データのある17セクションのみ)
5. **図解** — タイムライン・構造図・対比表(意味のある場合のみ)
6. **例文** — 自然な英文 + 和訳 + 学習対象のハイライト + 音声
7. **対比** — 紛らわしい構造との比較(該当する場合)
8. **構造チェック** — 主語・動詞・目的語・補語・文型を判断する追加問題(構造データのあるセクションのみ)
9. **クイズ** — 多肢選択2問以上、文脈を変えた追加問題
10. **即時フィードバック** — 正誤・理由・誤答が誤りである理由・正解文の音声
11. **まとめ** — 2〜5ポイント

### 英文の構造を読む(学習導線)

英文法ページは文法事項の一覧ではなく、「英文がどう組み上がっているか」の順に学べる導線を持つ。
導線は英文法ページからリンクで進む専用ページ(`/grammar/roadmap`)に置き、`src/content/grammar/roadmap.ts` の
1箇所で定義する。各ステップは既存セクションIDを参照し、レッスン(`/grammar/:lessonId`)のルーティングは変えない。

導線に入る前に、ページ前半で S / V / O / C / M の意味、英語の語順、5文型を示す(STEP 1 の詳しい解説)。
5文型は1文型につき代表例と2Dアニメーションを並べ、動詞のあとに何が続くかを目で確かめられるようにする。
アニメーションはレッスンの挿絵と同じ `scene(title, mode, frames)` 形式で、同じ再生UIを使う。

| STEP | ねらい | 参照するセクション(例) |
|------|--------|------------------------|
| 1 文の骨格 | S / V / O / C を見つけ、修飾語(M)と区別する | ページ前半 + u01-l1, u01-l2, u04-l1 |
| 2 動詞の変化 | 時制・進行形・完了形・助動詞・受動態で意味が変わる | u02-l1, u11-l1, u13-l1 |
| 3 骨格に情報を足す | 形容詞・副詞・前置詞句・to不定詞がどこに入るか | u05-l1, u05-l2, u08-l2, u10-l1 |
| 4 句を使う | 名詞句・形容詞句・副詞句が席を広げる | u03-l3, u08-l2, u10-l2 |
| 5 節を使う | 名詞節・形容詞節・副詞節を働きで分類する | u29-l1, u14-l1, u16-l1 |
| 6 文と文をつなぐ | 接続詞・関係詞・間接話法で2文を1文にする | u16-l1, u14-l1, u19-l4 |
| 7 複雑な英文を読む | 動詞 → 主語 → O/C → 修飾の順で解析する | u25-l2, u25-l3, u30-l2 |

構造図(breakdown)は英文の区画と役割(S / V / O / C / M)を示し、`skeleton` を添えると
「修飾語を外すと骨格はこれだけ」を見せられる。expansion は短文が段階的に長くなる(または長い節が
分詞句に圧縮される)過程を示し、足された語句を強調する。どちらも `src/content/types.ts` の
`LessonBlock` として定義し、UI・Markdown・PDF が同じデータから描画する。

### 5文型の視点(全セクション共通)

文の骨組みを S / V / O / C で捉える見方を、全118セクションに通す。

- 各セクションに「**文型の視点**」ブロックを1つ置き、その文法が文型でどう説明されるかを示す。
- すべての例文(対比の英文を含む)に、5文型のいずれかを示す**バッジ**と、その文がなぜその型かの
  **文型注記**を付ける。例文ブロックの10文が並べ替え10問の母集団になるのと同じデータから付与する。
- 判定は機械的に再現できるよう規約を定める(疑問文・命令文は平叙文に戻す、受動態・there is は
  第1文型 SV、名詞節・不定詞・動名詞は名詞の席なら1要素、副詞句・関係詞節は数えない、など)。
  規約は `src/content/grammar/patterns/types.ts` に、データは `src/content/grammar/patterns/` に置く。
- 教材ファイル(レッスン定義)は書き換えず、合成時に付与する。文型が欠けた例文があれば
  `content.test.ts` の検証で落ちる(全例文に文型が付くことを固定している)。

5文型は分類・暗記の対象ではなく、「まず動詞(V)、次に主語(S)を探し、O / C の有無で骨格を決め、
最後に修飾語(M)を確かめる」という手順のための道具として位置づける。この手順をそのまま体験させるのが
構造図(breakdown)と構造チェックで、どちらも `src/content/grammar/structures/` の同じデータを使う。

## 語彙セッションの必須動作

1. 対象プールから5語を選ぶ。復習が必要な語(再学習中 → 予定日超過)に半分(3語)まで充て、
   残りは必ず未出題語(新出語)に回す。同じ条件の候補が並んだときは、レベルの低い語(A2 → B1 → B2)を優先する
2. 英単語のみ提示 → 学習者が意味を想起 → 「わかる/わからない」
3. 選択後に必ず完全な解説を表示(意味・品詞・発音・音声・例文・例文音声・コロケーション・記憶フック)
4. 5語終了後、わからなかった語だけを再出題
5. わからない語が0になるまで繰り返し、0になったらセッション完了
6. 結果をローカル履歴に保存し、以後の選択優先度に反映(間隔反復)

## 音声練習の出題

音読・シャドーイングとディクテーションは、学んだ英文を声に出す・書き取る反復の場なので、
セッションの区切りを置かない。記録するのは文ごとの**実施回数だけ**で、実施回数の少ない文から順に
全体を1周ずつ回す(同じ回数の文の中ではランダムに選ぶ)。

周回の位置は実施回数だけから決まるので、別のカーソルを持たない。実施回数を同期すれば、
端末をまたいでも続きの文から回せる。出題は同じ回数の文の中でしか揺れないため、
1周のあいだに同じ文が2度出ることはない。全員が同じ回数になったら次の周に入り、終わりは作らない。
完了画面や「次のN問へ」も置かない(やめるのはモードの切り替えか、ページ移動で行う)。

正誤は記録しない — この練習の目的は「今復習すべき文」を当てることではなく、
多くの文に触れて口と耳を慣らすことなので、語彙のような間隔反復には乗せない。
ディクテーションの正解数は、その場の表示にだけ使う。

## 間隔反復アルゴリズム(シンプルで説明可能なもの)

各語について保持: 最終出題日時 / 出題回数 / わかる回数 / わからない回数 / 連続正解回数(streak) /
再学習フラグ(lapsed)。

出題間隔は `1日 × 2^streak`(上限60日)。「わかる」で streak を1増やして間隔を倍にする。
優先度は `経過日数 ÷ 間隔` で、1.0が予定日、1.0超が延滞を意味する。

「わからない」と答えた語は streak を0に戻し、再学習フラグを立てる。再学習中の語は間隔を待たず
次のセッションに戻す(復習枠まで。枠を超えるときは、レベルの低い語と古い取りこぼしを重みにして選ぶ)。
セッション内の再出題で「わかる」に
なっただけではフラグは降りない — 次のセッションでもう一度正解して初めて通常の間隔に戻る
(セッション内の周回では streak が1までしか伸びないため、連続正解2回が「別の機会での再現」を意味する)。

### レベルの重み付け

出題の選択はレベルを見て重み付けする。同じ条件の候補が並んだときは `A2 → B1 → B2` の順に優先し、
未出題語はレベルの低い語ほど選ばれやすくする(`LEVEL_WEIGHTS` = A2 3 : B1 2 : B2 1)。
対象プールの6割が B2 なので、語数差のままだと出題も B2 に偏ってしまうため。
復習の必要性(再学習中・予定日超過)はレベルより常に優先する。再学習中の語が枠を超えるときだけは、
レベル重みに経過日数を掛けた抽選にして、古い取りこぼしも戻るようにしている。

セッションの枠配分も固定する。復習(再学習中+予定日超過)は半分の3語まで、残りの枠は必ず新出語に回す。
これを上限なしにすると、再学習中の語が5語を占めて新出語が1語も出なくなる(実際にその状態になりやすかった)。
さらに新出語の先頭1語は「未出題が残っている一番低いレベル」から取るので、未出題のA2が残っている限り、
どのセッションにもA2が最低1語は入る。

5語はまず再学習中の語で埋め(上限なし)、次に延滞している語(スコア1.0以上)で半分まで、
残りを未出題語から選ぶ。
未出題語が尽きた場合だけ、予定日前の語も延滞順に補う。同点候補はFisher–Yatesで先に混ぜ、
配列sortの比較関数には乱数を使わない。streak を持たない古い履歴は `わかる回数 − わからない回数`
から推定するため、移行処理は不要。

SM-2 のような難易度係数(EF)は実装しない — 間隔の倍増とリセットだけで忘却曲線に追随でき、
学習者にも「連続で正解すると次は先になる」と一文で説明できるため。

## 音声設計

- 既定アクセント: American English (`en-US`)。ページごとにアクセントを切り替えない。
- SpeechService 抽象の背後に Web Speech API を隔離。将来クラウドTTSや事前生成音声へ移行可能。
- 通常速度(rate 1.0)とスロー速度(rate 0.7 — 不自然にならない範囲)。
- 再生は常に任意。音声なしでも全レッスンを理解できる(書かれた英文は常に表示)。
- 同時再生はしない — 新しい再生開始時に既存の再生を停止。
- TTS非対応ブラウザでは音声ボタンを無効表示にし、ページは壊さない。
- TTSに渡すテキストはクリーンな英文のみ(ハイライトマークや注記を含めない)。
