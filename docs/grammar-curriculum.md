# 文法カリキュラム設計(Reach B2 全体)

CEFR準拠の文法進行(English Grammar Profile / Cambridge系のCEFRレベル分けを参考、SOURCES.md 参照)に
基づき、A2復習 → A2+ → B1 → B1+ → B2 の5段階・33ユニット・118セクションで構成する。
全118セクションは `src/content/grammar/` に実装済みで、合計676問の理解度チェックを含む。
B2の34セクションは到達判定に足る演習量を確保するため1セクション10問、それ以外は4問とする。
各セクションには個別の補強解説と追加例文3つを用意しており、例文は10文にそろえて全体で1,180文ある。

設計ルール:
- 1セクション = 3〜15分。大トピックは複数セクションに分割。
- 前提(prereq)は直前レベルまでのセクションIDで示す。空欄は「同ユニット内の直前セクション」が前提。
- 各セクションは必ず「目標 → 解説 → 文型の視点 → (図解) → 例文 → (対比) → クイズ → まとめ」の構造を持つ。
- 全118セクションに「文型の視点」を置き、例文と対比の英文(計1,498件)に5文型(SV・SVC・SVO・SVOO・SVOC)の
  バッジと注記を付ける。判定の規約とデータは `src/content/grammar/patterns/` にまとめる。
- IDは `u<ユニット>-l<番号>`。
- クイズはレベル別に必要数を課す(B2は10問、それ以外は4問)。`REQUIRED_QUIZ_COUNT` が定義。
- B2の例文はレッスン平均12語以上とする(`MIN_AVG_EXAMPLE_WORDS`)。倒置・cleft・分詞構文は
  長い文を制御するための道具なので、短文だけで練習させるとレベル相当のインプットにならない。

## カバレッジの根拠

B2 に必要な文法領域(文構造 / 時制 / 冠詞・名詞 / 代名詞・限定詞 / 形容詞・副詞・比較 /
前置詞 / 接続詞 / 不定詞・動名詞 / 法助動詞(基礎〜推量・過去推量) / 完了形 / 受動態(基礎〜発展) /
関係詞(基礎〜発展) / 条件文(0〜3型・混合・wish) / 人の言葉の伝え方・丁寧な質問 / 使役・知覚 / 分詞 /
談話標識 / 名詞節・強調・倒置・省略 / 未来完了・未来進行 / 過去から見た未来 / 倒置による条件文 /
the 比較級構文 / 冠詞・数量詞・句動詞の再訪)をすべて含む。
これは Cambridge の CEFRレベル別文法参考資料および一般的なB2試験(FCE)のシラバスで
要求される領域を網羅しており、B2の読解・作文・会話に必要な文法へ段階的に
到達できる構成である。

## 前提関係(レベル間)

- A2+ は A2 全体を前提とする。B1 は U01〜U10、B1+ は U11〜U16(特に現在完了・条件文)、
  B2 は B1+ 全体を前提とする。
- 特筆すべき依存: u17(完了進行)← u11(現在完了)。u18(過去完了)← u11。u22(3型)← u15(1・2型)。
  u23(混合)← u22。u25-l2(縮約)← u14(関係詞)。u26 ← u13(受動態)。u27 ← u14。
  u32-l1 ← u31-l1(時制の総合選択)。u32-l3 ← u23-l1(混合条件文)と u30-l2(倒置)。
  u33 は A2 の u03(冠詞)・u04(限定詞)を B2 水準で再訪する位置づけ。
- ユニット内は原則、直前セクションが前提。
